# RecordFlow Downloads

Download the latest RecordFlow desktop installers from this repository.

## Files

- `RecordFlow-Desktop-Linux.AppImage`
- `RecordFlow-Desktop-Linux.deb`
- `RecordFlow-Desktop-Linux.rpm`

## Install

### AppImage

```bash
chmod +x RecordFlow-Desktop-Linux.AppImage
./RecordFlow-Desktop-Linux.AppImage
```

### Debian / Ubuntu

```bash
sudo apt install ./RecordFlow-Desktop-Linux.deb
```

### Fedora / RHEL / similar

```bash
sudo dnf install ./RecordFlow-Desktop-Linux.rpm
```

## Notes

- The source code stays in the private RecordFlow repo.
- This repo is only for public installer files.
